Dependencies :

sudo npm install tauri on ./peer/

Packages :
sudo apt install libsoup2.4-dev libpango1.0-dev  libgdk-pixbuf-2.0-dev libgtk-3-dev libjavascriptcoregtk-4.0-dev libwebkit2gtk-4.0-dev


Pour lancer le programme :

$ make run

Pour lancer le programme en mode terminal :

$ make run-terminal

Pour lancer le programme et créer l'éxécutable dans le dossier build

$ make run-release
